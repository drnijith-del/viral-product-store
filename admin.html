🔗 Google Sheets Sync via Zapier

Status: Not Configured

Get webhook URL: zapier.com → Create Zap → "Webhooks by Zapier" (Trigger) → "Google Sheets" (Action)

📋 Setup Instructions

  1. Go to zapier.com and sign up (free)
  2. Create a new Zap → Click "Create Zap"
  3. Trigger: Search "Webhooks by Zapier" → Select "Catch Hook"
  4. Copy the Webhook URL that appears
  5. Action: Search "Google Sheets" → "Create Spreadsheet Row"
  6. Connect your Google Account
  7. Select/Create Spreadsheet: Name it "instahype-products"
  8. Map fields: name, desc, price, badge, image
  9. Publish the Zap
  10. Paste the Webhook URL in the box above and click Save
  11. Every time you add a product, it auto-syncs to Google Sheets! ✨
